# IEEE 754 부동소수점 구조 (단정도, 32비트)

## 정의

부동소수점 수를 이진수로 표현하는 표준 규격. 32비트를 부호/지수/가수 세 부분으로 나눠서 저장함.

```
31        30      23 22                    0
[ sign ][   exponent  ][      mantissa       ]
  1비트      8비트              23비트
```

## 원리 — 값 계산 공식

exponent 필드 값(E, 0~255)에 따라 세 케이스로 나뉨.

- **정규화(Normalized): 0 < E < 255**
  `value = (-1)^sign × 1.mantissa × 2^(E - 127)`
  가수 앞에 암묵적으로 1이 붙음(`1.xxx`).
- **비정규화(Denormalized): E = 0**
  `value = (-1)^sign × 0.mantissa × 2^(-126)`
  가수 앞에 0이 붙고, 지수는 `-126`으로 고정(E-127 아님).
- **특수값: E = 255**
  - mantissa = 0 → `±무한대`
  - mantissa ≠ 0 → `NaN`

## 이유 — 설계 근거

- **암묵적 1**: 정규화된 이진수는 항상 `1.xxx × 2^n` 꼴로 유일하게 표현됨. 맨 앞자리가 1인 게 보장되니 저장을 생략해서 23비트로 24비트 정밀도 효과를 냄.

- **bias 인코딩**: 지수를 부호 있는 정수 대신 127을 더해서 저장 → 지수 필드가 항상 양의 정수 범위. 덕분에 부호가 같은 두 float는 비트 패턴을 정수처럼 비교해도 크기 순서가 맞음.

- **denorm 존재 이유**: 정규화 수만 쓰면 최소 양수와 0 사이에 큰 gap이 생김. denorm으로 그 gap을 메꿔서 0 근처에서 정밀도가 급격히 끊기지 않고 서서히 줄어들게 함(gradual underflow).

## 핵심 포인트

- bias = 127. E=0, E=255는 특수 용도로 예약, 실제 정규화 지수 범위는 E=1~254 → 실제 지수 -126~127.
- **denorm의 지수는 -126, -127 아님** — E=0인데도 E-127 공식을 안 쓰고 -126 고정. denorm/정규화 경계(E=1)에서 지수가 매끄럽게 이어지도록 일부러 이렇게 정의함. (floatScale2, floatPower2에서 제일 실수하기 쉬운 지점)
- +0과 -0이 따로 존재함(부호만 다름).
- NaN은 자기 자신과도 같지 않음(`NaN != NaN`) → 비트 비교로 float 동등성 판단하면 안 됨.
