# Data Lab 핵심 패턴 정리

CS:APP Data Lab 전체 문제(정수 9개 + float 3개)에서 반복적으로 쓰인 기법들을 패턴 단위로 정리.

## 1. 큰 상수를 못 쓸 때 — 조각내서 조립

`allOddBits`처럼 0xAAAAAAAA 같은 큰 상수는 직접 못 씀(0~0xFF만 허용). 대신 바이트 단위 패턴을 만들어서 shift로 이어붙임.

```c
~((0xAA << 24) + (0xAA << 16) + (0xAA << 8) + 0xAA)
```

## 2. 드모르간 법칙으로 연산자 우회

`bitXor`처럼 `^`, `|` 없이 `~`, `&`만으로 원하는 논리 연산을 만들어야 할 때, 드모르간 법칙(`A|B = ~(~A & ~B)`)을 뒤집어서 우회.

```c
int bitXor(int x, int y) { return ~(~(x & ~y) & ~(~x & y)); }
```

## 3. 마스크 기반 조건 분기 (`if` 없이 삼항연산자 흉내)

boolean 값(0 또는 1)을 all-0/all-1 마스크로 바꿔서, 두 값 중 하나를 마스크로 골라내는 패턴. `conditional`이 대표 예시고, `howManyBits`의 여러 단계도 같은 구조 반복.

이 패턴의 뿌리는 `negate`에서 나온 2의 보수 성질 `-x = ~x + 1`. 이후 나오는 불리언→마스크 변환, 부호 판별 트릭 전부 이 공식이 베이스.

```c
int mask = (!(~x + 1) << 31) >> 31;   // 참이면 0xFFFFFFFF, 거짓이면 0
return (mask & z) + (~mask & y);       // mask로 z or y 선택
```
- 불리언→마스크 변환은 `~bool + 1`이나 `(bool << 31) >> 31` 둘 다 동치.

## 4. 부호비트/오버플로를 이용한 대소·범위 판별

뺄셈 결과의 부호비트(`>>31`)로 크기 비교를 판별하되, **오버플로 시 부호비트가 뒤집히는 함정**을 피해야 함. `isAsciiDigit`, `isLessOrEqual`이 이 문제를 겪음 — 그래서 `isLessOrEqual`은 단순 뺄셈 부호 체크 하나로 안 끝나고, "부호가 다른 경우"를 따로 처리하는 항이 추가로 붙음.

```c
// x <= y 판별 시 오버플로 안전하게 처리
!!((x + (~y + 1)) >> 31) | (!(x ^ y)) | ((x >> 31) & (!(y >> 31)))
```

`isTmax`는 다른 각도의 오버플로 트릭 — Tmax는 `x+1`이 Tmin으로 오버플로되는 유일한 지점이라는 성질을 이용.

## 5. 부호 비트 추출 트릭 (`x`가 0인지 판별)

`logicalNeg`에서 쓴 핵심 통찰: `x | (-x)`의 MSB는 x가 0이 아닌 이상 항상 1. (x, -x 중 하나는 반드시 음수이므로.) x==0일 때만 둘 다 0이라 MSB도 0.

```c
int logicalNeg(int x) { return ((x | (~x + 1)) >> 31) + 1; }
```

## 6. 이분탐색으로 최상위 유효 비트 위치 찾기

`howManyBits`의 핵심. 16→8→4→2→1로 절반씩 좁혀가며 "최상위 1이 어디 있는지" 탐색. 음수는 `~x`로 뒤집어서(무조건 양수 형태로 정규화) 같은 로직 재사용.

- 각 단계: 상위 절반에 1이 있으면 그쪽으로 좁히고 카운트 누적, 없으면 하위 절반 유지.
- 예외 케이스(x==0, x==-1)는 별도 처리 필요 — 최소 표현 비트 수가 1이라는 특수 규칙.

## 7. IEEE 754 필드 추출·재조합 (float 3형제 공통)

`floatScale2`/`floatFloat2Int`/`floatPower2` 모두 같은 골격: S/E/M 필드를 shift+mask로 뽑아내고, 계산 후 다시 shift+OR로 조립. 구조 자체는 [[ieee754-floating-point]] 참고.

```c
unsigned S = (uf >> 31) & 1;
unsigned E = (uf >> 23) & 0xFF;
unsigned M = uf & 0x7FFFFF;
// ... 계산 후
return (S << 31) | (E << 23) | M;
```

함수별로 갈리는 지점:
- **floatScale2**: E를 그대로 두고 M만 다루면 안 되고, denorm(E=0)에서 정규화로 넘어가는 경계(캐리 발생) 처리가 핵심.
- **floatFloat2Int**: 지수(`E-127`)가 음수면 0, 31 넘으면 오버플로(`0x80000000u`), 그 사이는 가수를 지수만큼 shift해서 정수로. 음수는 부호 따로 처리.
- **floatPower2**: 반대로 지수 x 자체가 입력. 결과가 denorm 범위(-127~-149)면 가수를 shift해서 만들고, 그보다 작으면 0, normalized 범위 넘으면 +INF.

## 8. 연산자 개수 줄이기 — 중복 계산은 변수에 캐싱

dlc는 코드에 등장한 연산자를 그대로 카운트하기 때문에, 같은 부분식(`!!(y>>16)` 같은)을 여러 번 쓰면 그때마다 다 카운트됨. = (대입)는 op로 안 세므로, 한 번 계산해서 변수에 담아두고 재사용하면 실제 연산자 호출 수가 줄어듦.
