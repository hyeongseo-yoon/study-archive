# coursework

대학교 수업 시험공부 전용 공간. git 추적됨.

## 용도
- 학기 중 수강 과목별로 시험공부 노트를 자유롭게 작성한다.
- 기존 아카이브(`computer-science/` 등)의 개념노트 형식에 얽매이지 않고, 시험 대비에 편한 형태로 정리한다.
- 복습 시스템(`#review` / `#incomplete` / `#completed` 태그)은 여기서는 적용하지 않는다.

## 구조
- 과목별 폴더로 나눈다: `coursework/<학기>/<과목명>/`
  - 예: `coursework/2026-2/operating-systems/`
- 각 과목 폴더 안 `materials/`는 강의자료(PDF·슬라이드 등)와 강의자료를 통한 수업을 진행할때 만든 커리큘럼 보관용. gitignore 처리되어 추적 안 됨.
- 각 과목 폴더 안 `notes/`는 PDF 강의자료에 대응하는 정리 노트(`chapter-N.md`) 저장 위치.
- 각 과목 폴더 안 `class-note/`는 실제 수업에서 오간 설명·예시·Q&A를 담은 수업노트(`chapter-N.md`) 저장 위치. `notes/`의 정리 노트와는 별도 파일.

## PDF 강의자료 → 정리 노트 자동 생성
`materials/`에 PDF가 있으면, 그 PDF에 대응하는 정리 노트(예: `chapter-N.md`)를 자동으로 만든다(이미 있으면 갱신).

- PDF의 모든 페이지를 읽고, 내용을 빠짐없이 노트에 정리한다 (제목/로드맵 슬라이드처럼 내용이 없는 페이지는 제외).
- 노트의 각 섹션/소제목 옆에 해당 내용이 나오는 슬라이드 번호를 `*(슬라이드 p.N)*` 또는 `*(슬라이드 p.N~M)*` 형식으로 표시한다. 슬라이드 번호는 슬라이드 우측 하단의 쪽번호(예: "Introduction: 1-5" → p.5) 기준.
- 한 섹션이 여러 슬라이드에 걸쳐 있으면 범위로, 소제목 내에서도 세부 항목별로 슬라이드가 갈리면 항목별로 표시한다.
- 노트를 만들고나서, 노트가 PDF의 내용을 빠짐없이 다루고 있는지 다시 한번 확인하고 빠진 부분이 있다면 노트에 추가한다.
## 수업자료 최신화 루틴
사용자가 "수업자료 최신화하자" 같은 말을 하면, LMS(learning.hanyang.ac.kr)에서 직접 내려받는다.
1. Playwright MCP로 LMS에 접속한다. 아이디 비번은 `~/.config/hanyang-lms/credentials` 문서 참조해서 로그인한다.
2. LMS 과목명을 `coursework/` 밑의 기존 과목 폴더명(영문)에 매칭한다. 이름만으로 애매하면 사용자에게 확인한다.
3. 과목별 항목 목록은 Canvas API(`/api/v1/courses/<id>/modules?include[]=items`, 로그인 세션으로 호출)로 뽑는다. 항목 제목을 `materials/` 파일명(확장자 제외)과 대조해 후보를 거른다.
4. 후보 항목 페이지(`/courses/<id>/modules/items/<item_id>`)를 열고, 뷰어 iframe(`hycms.hanyang.ac.kr/em/...`)의 `content_type=pdf`인 것만 받는다 (mp4/movie/exe/설문은 제외). 강의자료만 받는다: 과제(HW 등)·syllabus·기타 안내/잡다한 PDF는 제목만 보고 제외하고, 애매하면 사용자에게 확인한다. 뷰어 안의 `.vc-pctrl-download-btn`을 `evaluate`로 `.click()`하고(마우스 클릭은 헤더가 가려서 안 됨), `download` 이벤트를 `saveAs`로 `materials/<사이트 제공 파일명>`에 저장한다. 타임아웃 나면 4초 대기 후 재시도. 이미 있는 파일은 건드리지 않는다.
5. 과목별로 신규/스킵 내역을 정리해서 보고한다.

## 학습 루틴
사용자랑 특정 과목의 수업자료를 같이 공부한다. 수업자료를 읽을때 pdf 파일을 사용하지 않고 미리 만들어놓은 pdf 대응하는 노트(notes 디렉토리에 있음)를 통해서 수업내용을 읽고 이를 기반으로 학습을 사용자와 같이 진행한다. 

이렇게 커리큘럼 없이 노트(강의파일) 기반으로 수업을 진행할 때는, 노트에서 학습해야할 섹션 목록을 체크리스트로 만들어 수업 시작할 때 제시하고, 각 섹션이 끝날 때마다 갱신해서 보여준다. 내용이 길어 진행 중 섹션을 빠뜨리는 것을 막기 위함. 또한 수업을 진행할 때 강의 슬라이드의 어느 페이지를 다루고 있는지도 간단히 표기하면서 수업을 진행한다. 수업이 끝나면 수업에서 pdf 정리노트에 있는 내용들을 빠짐없이 설명하였는지 확인하고, 빠진 부분이 있으면 보충한다. 이후 다음과 같은 작업을 진행한다.

수업때 다룬 섹션 목록을 번호 목록(1. 2. 3...)으로 해당 pdf 정리 노트(`notes/chapter-N.md`) 파일 맨 하단에 추가한다. 그리고 수업 중 에이전트가 실제로 설명했던 텍스트를 정리해서 복습노트를 만든다.(수업했던 텍스트를 그대로 가져오고, 쉽게 복습할 수 있도록 가독성 좋게 텍스트를 다듬는다. 다만 수업했던 내용들은 하나도 빠짐 없이 전부 보존되어야한다.) `class-note/chapter-N.md`에 저장한다. 저장 후 pdf 대응 정리노트에 있는 내용을 빠짐없이 다루고 있는지 확인(시험공부하는데 문제 없을 정도로만)한 후 수업을 마무리 한다.(만약 빠트린 부분이 있으면 보충하고 마무리한다)
## 학기말 이관 루틴
매 학기 종료 시 실행한다.
1. 그 학기 전 과목 노트를 함께 훑는다.
2. 아카이브에 남길 가치가 있는 개념만 선별한다.
3. 선별한 내용은 `note-taking-workflow`를 태워 정식 개념노트로 승격시킨다.
4. 이관이 끝난 과목 원본은 유지할지 삭제할지 그때 판단한다.
