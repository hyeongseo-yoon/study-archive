# coursework

대학교 수업 시험공부 전용 공간. git 추적됨.

## 용도
- 학기 중 수강 과목별로 시험공부 노트를 자유롭게 작성한다.
- 기존 아카이브(`computer-science/` 등)의 개념노트 형식에 얽매이지 않고, 시험 대비에 편한 형태로 정리한다.
- 복습 시스템(`#review` / `#incomplete` / `#completed` 태그)은 여기서는 적용하지 않는다.

## 구조
- 과목별 폴더로 나눈다: `coursework/<학기>/<과목명>/`
  - 예: `coursework/2026-2/operating-systems/`
- 각 과목 폴더 안 `materials/`는 강의자료(PDF·슬라이드 등)와 강의자료를 통한 수업을 진행할때 만든 커리큘럼 보관용. gitignore 처리되어 추적 안 됨.

## PDF 강의자료 → 노트 자동 생성
`materials/`에 PDF가 있으면, 그 PDF에 대응하는 노트(예: `chapter-N.md`)를 자동으로 만든다(이미 있으면 갱신).

- PDF의 모든 페이지를 읽고, 내용을 빠짐없이 노트에 정리한다 (제목/로드맵 슬라이드처럼 내용이 없는 페이지는 제외).
- 노트의 각 섹션/소제목 옆에 해당 내용이 나오는 슬라이드 번호를 `*(슬라이드 p.N)*` 또는 `*(슬라이드 p.N~M)*` 형식으로 표시한다. 슬라이드 번호는 슬라이드 우측 하단의 쪽번호(예: "Introduction: 1-5" → p.5) 기준.
- 한 섹션이 여러 슬라이드에 걸쳐 있으면 범위로, 소제목 내에서도 세부 항목별로 슬라이드가 갈리면 항목별로 표시한다.

## 학기말 이관 루틴
매 학기 종료 시 실행한다.
1. 그 학기 전 과목 노트를 함께 훑는다.
2. 아카이브에 남길 가치가 있는 개념만 선별한다.
3. 선별한 내용은 `note-taking-workflow`를 태워 정식 개념노트로 승격시킨다.
4. 이관이 끝난 과목 원본은 유지할지 삭제할지 그때 판단한다.
