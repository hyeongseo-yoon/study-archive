### 파일트리
### 파일 트리 열기: `Space` + `e`

| **기능**      | **단축키 (Neo-tree 안에서)** | **설명**                        |
| ----------- | ---------------------- | ----------------------------- |
| **창 끄기/켜기** | `Space + e`            | VSCode의 `Ctrl + B`와 같은 역할     |
| **파일 열기**   | `Enter`                | 선택한 파일을 편집창에서 열기              |
| **파일 생성**   | `a`                    | 새로운 파일이나 폴더 만들기 (Add)         |
| **이름 변경**   | `r`                    | 파일 이름 바꾸기 (Rename)            |
| **삭제**      | `d`                    | 파일 삭제 (Delete)                |
| **도움말**     | `?`                    | Neo-tree 안에서 쓸 수 있는 전체 단축키 보기 |
### 창 분할 

- **`space + |`** (Shift + ): 화면을 **세로**로 분할 (옆에 새 창 띄우기)

- **`Space + -`**: 화면을 **가로**로 분할 (밑에 새 창 띄우기)

**현재 버퍼만 닫기**: **`<leader>bd`** (Buffer Delete)
### 이동

- shift(탭 이동), ctrl(분할된 창 이동)

### 터미널 

- **`space + f + t`**

수정 단축키

- **`A`** (Shift + a): 줄 끝으로 이동하면서 동시에 **입력(Insert) 모드**로 전환

- **`I`** (Shift + i): 줄 맨 앞으로 이동하면서 동시에 **입력 모드**로 전환

- `^`** (Shift + 6)들여쓰기(공백) 무시하고 **실제 코드가 시작되는 첫 글자**로 이동

- **`0`** (숫자 0)공백 상관없이 무조건 해당 줄의 **첫 번째 칸**으로 이동.

- **`$`** (Shift + 4)해당 줄의 가장 마지막 글자로 점프

기타 기능
 space xx → 파일 전체 에러/경고 한눈에 모아보기
 space uk -> 자동완성 켜기 끄기

### 텍스트 이동 (Motion)

**단어 단위**

| 키 | 기능 |
|---|---|
| `w` | 다음 단어 시작으로 |
| `W` | 다음 단어 시작 (공백 기준, 구두점 무시) |
| `e` | 단어 끝으로 |
| `E` | 단어 끝 (공백 기준) |
| `b` | 이전 단어 시작으로 |
| `B` | 이전 단어 시작 (공백 기준) |
| `ge` | 이전 단어 끝으로 |

**화면/문서 단위**

| 키 | 기능 |
|---|---|
| `gg` | 문서 맨 위로 |
| `G` | 문서 맨 아래로 |
| `{숫자}G` 또는 `:숫자` | 특정 줄로 이동 |
| `H` / `M` / `L` | 화면 맨 위/중간/맨 아래 |
| `Ctrl-d` / `Ctrl-u` | 반 페이지 아래/위 (커서도 같이 이동) |
| `Ctrl-f` / `Ctrl-b` | 한 페이지 아래/위 |
| `Ctrl-e` / `Ctrl-y` | 화면만 한 줄 아래/위로 스크롤 (커서 줄 고정) |
| `zz` | 커서 줄을 화면 중앙으로 |
| `zt` / `zb` | 커서 줄을 화면 맨 위/아래로 |

**문단/괄호**

| 키 | 기능 |
|---|---|
| `{` / `}` | 이전/다음 빈 줄(문단) |
| `%` | 짝 맞는 괄호로 `()` `{}` `[]` |

**문자 찾기 (한 줄 내)**

| 키 | 기능 |
|---|---|
| `f{char}` | 다음 해당 문자로 |
| `F{char}` | 이전 해당 문자로 |
| `t{char}` | 해당 문자 바로 앞까지 |
| `T{char}` | 해당 문자 바로 뒤까지 (역방향) |
| `;` | 마지막 f/t/F/T 반복 |
| `,` | 반대 방향으로 반복 |

**검색**

| 키 | 기능 |
|---|---|
| `/{pattern}` + Enter | 아래로 검색 |
| `?{pattern}` + Enter | 위로 검색 |
| `n` / `N` | 다음/이전 검색 결과 |
| `*` / `#` | 커서 아래 단어 다음/이전 검색 |

**마크/점프**

| 키 | 기능 |
|---|---|
| `` `` `` | 이전 위치로 |
| `Ctrl-o` / `Ctrl-i` | 점프 목록 뒤로/앞으로 |

**폴딩 / 텍스트 오브젝트**

| 키 | 기능 |
|---|---|
| `za` | 커서 위치 fold 토글 (접혀있으면 펴고, 펴있으면 접기) |
| `yaf` | 함수 전체 복사 (시그니처+`{}`+몸통, mini.ai + treesitter `@function.outer` 기반) |
| `yif` | 함수 몸통 안쪽 내용만 복사 (시그니처, `{}` 제외, treesitter `@function.inner` 기반) |
